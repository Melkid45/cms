# Process

Preview: /process-collection.html. Seven partials share process.scss: steps, vertical, image, cards, interactive, icons, compact cards. Four consistent phases: Discover, Plan, Design, Deliver. The first two variants have no separator borders. Compact cards use 4 desktop / 2 tablet / 1 mobile columns; icons use the existing Lucide Handshake, ScanEye, Layers, Leaf paths (ISC).

Shared template typography, colors, container and radius; section-stack owns the 150px gaps. Header compositions vary (description, button, short line + button, Lucide ArrowUpRight link). No arbitrary header numbering; numbers within steps express the sequence.

Only variant 5 uses process.js for accessible tabs with keyboard support. All panels share a grid cell to reserve stable height. Inactive panels are inert and hidden from assistive technology; without JS all content stays readable. Old sections unchanged.
