# Pricing

Preview: /pricing-collection.html. Six partials share pricing.scss: packages, list, pair, compare, custom, horizontal (adapted from experimental/v3/pricing.html: package/price left, inclusions middle, action right). All prices are fictional demonstration content, not published offers. No checkout or payment integration; actions open email with the relevant subject.

Shared template typography/container/buttons/radius and 150px section-stack spacing. Icons: installed Lucide Check (ISC). Native semantic comparison table scrolls within its own labeled, keyboard-focusable region on smaller screens. Other layouts stack responsively. No JS needed. Old sections remain untouched.

pricing-v9 (products): grid of product cards — photo (cover by default), optional badge, up to four spec rows, price with optional old price, order link. Empty badge, old price and spec rows are hidden. 4/3/2/1 columns by container width. Hover is a soft shadow only.

pricing-v20 (shop): compact product cards — photo well, discount badge + tag (both optional), title, four spec rows (label + value), price with optional old price, order button; optional promo tile (dark image card spanning two columns: kicker, heading, text, button; hidden when its heading is empty) and an optional centred "see all" button. Heading/lead line hidden when the heading is empty. 4/3/2 columns; on phones a horizontal card (photo left, values only).
pricing-v21 (catalog): pricing-v20 cards (up to 80) next to a filter sidebar — sort select (cheapest / most expensive / original order), four chip groups ("any" + 8 chips; empty chips and groups with an empty title are hidden), price ceiling slider (range from the card prices), reset. Each card has a hidden "filter tags" text (comma separated, e.g. "AMD, RTX 5060, DDR4"): chips match these tags exactly (OR inside a group, AND between groups). Client-side only (admin `shop-widgets.ts`). On narrow screens filters fold behind a "Filters" button.
pricing-v22 (product): product page block — photo with up to four thumbnails (hidden when empty), kicker, title, subtitle, four spec tiles, five option groups (two choices each; "+N" in the second line is added to the price on click), a "pick" row (e.g. case choice → link), four fact rows with fixed icons (truck, clock, pin, shield), dark buy bar (summary line, price, old price, order link) and a 12-row specification panel (empty rows hidden).
pricing-v23 (configurator): picture of the current choice + numbered steps (`<details>`, one open at a time). Template 0: up to 8 options with a picture (choosing one also changes the big picture), template 1: 8 text options. Choosing an option writes its name/price into the step; total = all step prices + the "base" line (e.g. motherboard). Static, no backend.
pricing-v24 (checkout): static visual of an order form (summary column with rows and total; private/company and pickup/delivery toggles, name/phone/e-mail inputs, pickup card with map links, three check rows, send button, note). It is NOT a form: sending orders needs a shop backend.
pricing-v23 update (pass 2): a fourth step template has `open` — use it for the step that should be open on load (one per configurator); the "base" line can be hidden by site CSS and still counts in the total.

pricing-v25 (option picker): pop-up (`data-modal="case"`, opens from links to `#case` on the same page) with a heading, subtitle and option cards (picture, optional looping muted clip that plays on hover / when chosen, name, price change like "Included" or "+30 €"); cards with an empty name are hidden. Link a pricing-v22 "pick" row to `#case`: choosing a card writes its picture/name/price into that row, adds the "+N" to the product price, shows the "done" text as a short notice and closes the pop-up (`shop-widgets.ts`); the cart sends the choice as an extra option and the server prices it from this published block (`lib/builder/shop.ts`). Up to 40 cards.
pricing-v22 update: the four fact rows are links (url fields, e.g. `#info-1`…`#info-4` to open the panels of a contact-v29 info pop-up on the same page).
