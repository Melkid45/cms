# FAQ
Seven variations: split list, two-column list, surface panel, categorized lists, individual surface cards, centered narrow list, list with photo/contact aside.
Native details/summary supports mouse and keyboard and multiple open answers.
Import faq.js once on the host page: each FAQ section always keeps at least one answer open, across both columns/categories. The last open answer cannot be closed until another is opened. Without JavaScript, native disclosures remain usable.
Height transitions run for 280ms, with automatic height restored afterward; quick reversals start at the current rendered height. Reduced-motion preferences disable animation. Lucide Plus rotates into a close icon.
Shared heading/text classes and container, 150px collection spacing. Demo text must be adapted to the actual service.
