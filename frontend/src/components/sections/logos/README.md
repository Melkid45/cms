# Logos
Partner / supplier logo strips.
- logos-v40 Marquee: centred small heading and an endless, slowly moving row of greyscale logos with soft fading edges. Logos are a repeatable list (add/remove in the editor). The site script clones the row once for a seamless loop; without the script, or with reduced motion, the logos sit in a static wrapped row. Hover pauses the motion.
Demo logos in `public/images/logos/` are invented wordmarks; replace them with the client's partners.
