# Calculator
Price estimate forms that send the request to the website inbox.
- calculator-v40 Price Modal: a pop-up window (opened by any link to `#calc` on the page, or by opening the page with `#calc` in the address). Type choice (two options), width / height / depth in mm, name, email, address, live estimate and submit. Estimate = width in metres x "price per metre" (the hidden 700 setting, editable in the editor as the first hidden text; the next hidden text is the currency sign). The server recomputes the estimate from the saved price and adds it to the enquiry, so a visitor cannot change it. After sending, the success panel replaces the form.
In the page editor the window is shown inline so its texts can be edited. Put it once per page that should open it (forms post per page).
