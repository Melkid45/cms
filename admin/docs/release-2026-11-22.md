# Builder integration release

## Included

- 139 approved block/layout variants; 14 new variants imported from the shared frontend partials and SCSS, with actual Next-rendered previews.
- Site design: independent text/background/accent/button colours, heading/body fonts, container width, density, corners, primary/secondary button styles and hover behaviour.
- Services: content, image selection, draft/published state, centered modal, side panel, detail page and editorial page.
- Forms: configurable field type, name, label, placeholder, required state, width, order and select options. Shared definitions connect to buttons or replace template forms in contact sections.
- Button actions in section and repeater editors: link, form or service. Client accounts cannot alter schemas or bindings.
- Forms persist to the existing Inbox; server validates published-page/service bindings, signed tokens, fields and rate limits. Existing SMTP delivery remains in place.
- Catalog/product presentation, live cart quotes, optimized upload thumbnails, sitemap/robots and backup expiry work accumulated in the same workspace.

## Verified locally

- Production builds for admin and frontend; lint.
- Block library: all 139 variants, images/previews, escaping and long-content rendering.
- Isolated production role/workflow checks: permissions, publication, media, backups, shop/cart and SEO.
- Content integration API checks: persistent definitions, inline/button/service forms, durable submission, invalid options, missing references and draft-service protection.
- Real browser: all 14 new previews; form field editing/save; opening service and form dialogs; successful enquiry submission; 390px dialog/hero without horizontal overflow. Fixed a new-hero specificity conflict and token timing discovered by these checks.

## Boundaries

- Isolated test content is not imported into the live database.
- SMTP delivery to an external mailbox is not certified by the local tests.
- Rendering long content does not certify every one of the 139 layouts at every viewport. The browser overflow audit remains available separately.
- Earlier quality-audit notes describe the state at their date; this release supersedes their block count and Next.js version (now 16.4.6).
